# revund/workers/ruby

Ruby AST sidecar for Revund. Implements the universal `revund.worker.v1.Worker`
contract (same one ts-worker and php-worker speak); parses `.rb` / `.rake`
files via the whitequark/parser gem and returns the universal AST view the
structural detectors consume.

## Read first

See `/CLAUDE.md` for product context.
See `/proto/worker/v1/worker.proto` for the wire contract every worker speaks.

## Stack

- **Runtime:** Ruby 3.0+
- **AST library:** `parser` (whitequark/parser) — the gem RuboCop, Sorbet,
  Brakeman, and every serious Ruby static analyzer build on. Stable AST shape
  across Ruby 2.6 → 3.3 with exact line/column tracking and error recovery.
- **Round-trip:** `unparser` — used by the canonical-hash builder to produce
  a deterministic, normalized source form before hashing.
- **gRPC:** `grpc` (Google's official Ruby gRPC) + `google-protobuf`.

## RPCs

The universal `revund.worker.v1.Worker` service:

| RPC              | Status        | Purpose |
|------------------|---------------|---------|
| `Describe`       | required      | Self-identifies: name="ruby-worker", languages=["ruby"], capabilities=["parse"]. |
| `Health`         | required      | Liveness probe. |
| `Parse`          | required      | Returns the universal `ParsedFile` (requires + decls + methods + concerns). |
| `ResolveSymbols` | unimplemented | Bot's caller checks `capabilities` and skips this call. |
| `RunDiagnostics` | unimplemented | Same. Sorbet/Brakeman integration is a future capability. |

## Current status

**Full whitequark/parser implementation shipped.** `parser.rb` walks the AST and
emits the universal `ParsedFile` shape — requires, top-level decls, methods
(with hash + canonical_hash + blocks), and concern evidence. Cross-language
canonical hashes line up with ts-worker and php-worker so the structural
detectors can cluster shared shapes across languages.

The traversal:

1. `Parser::CurrentRuby.parse_file(absolute_path)` returns the AST root.
2. Iterative pre-order walk classifies nodes:
   - `:send` whose method is `require` / `require_relative` / `autoload`
     → ImportRef
   - `:class` / `:module` / `:def` / `:defs` / `:casgn` → DeclRef
   - `:def` / `:defs` → FunctionRef with line range, cyclomatic complexity
     (counts `:if` / `:while` / `:for` / `:case` / `:when` / `:and` / `:or`),
     language-specific hash + canonical hash, nested-block extraction
   - Concerns:
     - `session[` / `cookies[` / `Rails.cache` / `Rails.application.config` → state
     - ActiveRecord query methods (`.where` / `.find_by` / `.pluck` / etc.) → dataaccess
     - `Net::HTTP` / `Faraday` / `HTTParty` / `RestClient` → network
     - `File` / `IO` / `Dir` → io
     - `ENV[` → config
3. On `Parser::SyntaxError`, captures into `parse_error` and returns whatever
   partial AST was salvaged.

The canonical token vocabulary lives in
`core/pkg/structural/lang/canonical.go` — keep the Ruby mapping in `parser.rb`
in sync.

## Build + run

```bash
# Install deps
bundle install

# Generate proto stubs (requires grpc-tools)
bundle exec grpc_tools_ruby_protoc \
  --proto_path=../../proto \
  --ruby_out=proto \
  --grpc_out=proto \
  ../../proto/worker/v1/worker.proto

# Start the worker
bin/ruby-worker
# OR with custom port:
REVUND_RUBY_WORKER_PORT=50053 bin/ruby-worker
```

The server emits `ready: 0.0.0.0:<port>` once `add_http2_port` succeeds.
Spawning parents grep for that line to synchronize.

## Ports

- ts-worker → 50051
- php-worker → 50052
- ruby-worker → 50053

Override via `REVUND_RUBY_WORKER_PORT`.

## Error handling

- Sidecar must not crash on a single bad request — every handler is wrapped
  in `rescue`. Per-file parse errors land in `parse_error`; whole-batch
  failures return RPC `INTERNAL`.
- If `parser` gem isn't installed, log + exit non-zero. The bot falls back
  to NopClient on health-check failure.
